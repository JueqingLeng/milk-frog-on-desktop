# 奶蛙桌宠

Windows 10/11 x64 桌宠，透明背景、置顶显示，可拖动位置。不需要安装 Python、Electron 或额外的运行库。

双击 `MilkyFrog.exe` 启动。源码可通过 `奶蛙桌宠.code-workspace` 在 VS Code 打开。不要把 exe 单独移走，运行时需要旁边的 `assets` 文件夹。

## 操作

- 按住左键拖动奶蛙即可移动。
- 醒着时左键点击，播放一次大笑；睡觉时点击，在正面、背面之间翻身，被子一直盖住脖子以下。
- 把不要的本机文件或文件夹拖到奶蛙身上，即可送入 Windows 回收站。也可右键选择“投喂文件到回收站”或“投喂文件夹到回收站”。文件夹连同其中的内容一起回收，可在系统回收站中恢复。同时拖入父文件夹和其中的文件时，只处理父文件夹一次。
- 右键或托盘菜单选择“关闭桌宠”，奶蛙会招手两秒再退出；Alt+F4 也使用同一告别动作。重复点击关闭不会跳过动画或重新计时。
- 游戏时双手握住手柄。
- 大笑时使用侧身朝向使用者的姿势，双手放在腹前，身体上下抖动；学习时手持笔在书页上写字。

投喂只接收本机固定磁盘中的普通文件和文件夹，不接收网络/移动磁盘项目、符号链接、磁盘根目录、Windows/Program Files 及桌宠自己的目录和文件。包含这些受保护目录的上层文件夹也不能投喂。Windows 没有将操作标记为回收时会拒绝操作，不会改成永久删除。

## 独显自动退出

通过 DXGI 枚举显卡，优先用 D3D12 的统一内存（UMA）信息区分集显/独显，再用 Windows GPU Engine 性能计数器按显卡 LUID 匹配活动。忽略桌宠自身进程。

默认每秒检测一次，独显任一引擎连续三次达到 3% 时，奶蛙先抬手招手两秒，再自动关闭，减少瞬时波动造成的误关。手动关闭也会招手两秒。招手期间停止大笑，不再接收文件；若正在投喂，会等操作完成后再招手退出。检测失败不会误判为正在使用，右键“独显监测状态”可查看原因，详细记录在 `pet.log`。D3D12 不可用时按显卡厂商/专用显存判断，老显卡的识别精度有限。

可在关闭桌宠后修改 `settings.json`：`PetSize` 调整尺寸，`Sound` 控制音效，`GpuThresholdPercent`、`GpuConsecutiveSamples`、`GpuPollMilliseconds` 调整检测灵敏度。位置自动保存。

## VS Code 构建和运行

打开工作区后，按 `Ctrl+Shift+B` 构建。通过“终端 → 运行任务”选择“启动桌宠”或“验证桌宠”。构建调用 Windows 自带 .NET Framework 编译器。

关键文件：`src/PetForm.cs` 是桌宠交互，`src/Schedule.cs` 是作息，`src/WindowsRecycle.cs` 是回收站，`src/GpuMonitor.cs` 是独显监测，`src/LayeredWindow.cs` 是透明窗口。

网站的睡姿、被子和握手柄造型已同步到 `assets`。素材生成工具保留在原工作目录的 `work/export-desktop-assets.cjs`，之后修改网站图形可重新生成。

学习、睡觉、游戏等造型源于原个人网页的 SVG 绘制。捧腹大笑及招手采用 [timerring/codex-pet-naiwa](https://github.com/timerring/codex-pet-naiwa) 的动画帧，固定画布裁切为六帧循环，保留原动作中的仰头、捧腹和蹲身节奏。大笑音效沿用原音源。

来源与许可说明见 `assets/naiwa-source.txt`、`assets/naiwa-LICENSE.txt` 和 `assets/credits.txt`。上游原创内容为 MIT；上游另列的第三方素材不在该 MIT 授权范围内，此工程保留该说明，没有将它们重新声明为原创或统一 MIT 授权。项目没有设置开机自启动，也不需要管理员权限。

已通过作息边界、独显活动判定、透明窗口渲染、正背面素材，以及自动退出、菜单退出、窗口关闭的两秒招手检查。重复关闭不会跳过或延长告别。文件夹选择、父子路径去重、磁盘/系统/桌宠目录保护检查通过。此电脑的 AMD 集显和 NVIDIA RTX 5050 独显可识别。回收站集成测试在当前受限运行账号下被 Windows 拒绝，生成的测试文件保留，尚未验证文件及文件夹成功回收；首次在普通桌面账号使用时，可先投喂一份不需要的测试文本和测试文件夹，并检查系统回收站。
